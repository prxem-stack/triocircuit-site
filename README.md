# TrioCircuit information website

Public static game information, privacy policy and player support for TrioCircuit.

- Home: `index.html`
- Privacy: `privacy.html`
- Support: `support.html`
- Shared styles: `styles.css`

Publish the `main` branch root with GitHub Pages. No build, package installation, JavaScript, analytics or contact-form backend is required.

The playable game and its private-room server are hosted separately at https://triocircuit.premharsh-official.chatgpt.site/ . This repository contains website content only, not mobile signing data or player records.

Local preview: `python3 -m http.server 8766 --bind 127.0.0.1` from this folder.

Developer contact: premharsh.official@gmail.com
